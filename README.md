# Villa Poseidon — Premium Scrollytelling Landing

Премиальный лендинг виллы «Посейдон» (Геленджик) с canvas-покадровой анимацией по скроллу.

**Стек:** HTML5 · Tailwind CSS CDN · GSAP ScrollTrigger · Canvas

## Локальный запуск

```bash
npx serve .
```

## Структура

```
villa-poseidon/
├── index.html
├── public/frames/     # frame_001.webp … frame_150.webp
└── scripts/extract_frames.py
```
